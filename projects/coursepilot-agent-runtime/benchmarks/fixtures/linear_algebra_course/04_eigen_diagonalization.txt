# 线性代数课程讲义：特征值、特征向量与对角化

对于方阵 A，如果存在非零向量 x 和数 lambda，使得 Ax = lambda x，那么 lambda 是 A 的特征值，x 是对应的特征向量。特征向量表示在线性变换下方向不变的向量，特征值表示该方向上的伸缩比例。

特征值可以通过特征方程 det(A - lambda I) = 0 求得。每个特征值对应的特征子空间是齐次方程 (A - lambda I)x = 0 的解空间。

方阵 A 可对角化，表示存在可逆矩阵 P 和对角矩阵 D，使得 A = PDP^{-1}。A 可对角化的关键条件是存在 n 个线性无关的特征向量。此时 D 的对角线元素就是特征值，P 的列向量就是对应的特征向量。

对称矩阵具有很好的性质：实对称矩阵一定可以正交对角化，不同特征值对应的特征向量相互正交。这一性质在二次型、PCA 和谱分解中非常重要。

# 线性代数课程讲义：基、线性无关与维数

向量组线性无关表示没有任何一个向量可以由其他向量线性表示。等价地，方程 c1v1 + c2v2 + ... + ckvk = 0 只有零解 c1 = c2 = ... = ck = 0。线性相关则表示存在非零系数使线性组合等于零。

一组向量成为线性空间 V 的基，需要同时满足两个条件：第一，线性无关；第二，能够张成整个空间 V。线性无关保证表示不冗余，张成保证没有遗漏方向。基向量的个数称为空间的维数 dimension。

如果一个向量空间维数是 n，那么任意超过 n 个向量必然线性相关，任意少于 n 个向量不可能张成整个空间。基变换的本质是把同一个向量在不同坐标系下表示，坐标会变化，但向量本身不变。

矩阵的列秩可以理解为列向量张成空间的维数。列空间的一个基可以从主元列中选取。行秩和列秩相等，都等于矩阵的秩 rank。

## 💡 易错提醒

1. **特征值与特征向量**：必须熟练掌握特征多项式的计算、解齐次线性方程组的基本方法。  
2. **可对角化条件**：二阶对称矩阵一定可对角化；能正确写出 $P$ 和 $P^{-1}$ 是关键。  
3. **正定性与 Cholesky 分解**：注意正定矩阵的判定（特征值全正）和 Cholesky 分解的递推过程。  
4. **SVD 与特征分解的关系**：对称正定矩阵的奇异值分解即为其正交对角化，奇异值即为特征值。

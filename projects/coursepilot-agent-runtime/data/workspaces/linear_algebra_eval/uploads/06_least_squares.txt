# 线性代数课程讲义：最小二乘与正规方程

当线性方程组 Ax = b 无解时，可以寻找一个近似解，使残差 ||Ax - b|| 最小。这就是最小二乘问题。它常用于数据拟合、线性回归和过定方程组。

最小二乘的几何解释是：在 A 的列空间 Col(A) 中找一个向量 p = A x_hat，使它最接近 b。此时残差 r = b - p 必须与列空间 Col(A) 正交。

因为残差 b - A x_hat 与 A 的每一列都正交，所以得到 A^T(b - A x_hat) = 0，整理后就是正规方程 A^T A x_hat = A^T b。正规方程给出了最小二乘解的代数条件。

如果 A 的列向量线性无关，那么 A^T A 可逆，最小二乘解唯一。实际数值计算中常用 QR 分解求最小二乘，因为它比直接解正规方程更稳定。

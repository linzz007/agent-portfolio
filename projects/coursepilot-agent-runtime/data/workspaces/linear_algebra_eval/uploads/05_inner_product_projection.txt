# 线性代数课程讲义：内积、正交与投影

内积把两个向量映射成一个数，用来度量长度和夹角。欧氏空间中的标准内积是 x^T y。由内积可以定义范数 ||x|| = sqrt(<x, x>)，也可以定义正交关系：如果 <x, y> = 0，则 x 与 y 正交。

正交基是一组两两正交的基，标准正交基还要求每个基向量长度为 1。使用标准正交基时，坐标计算会非常简单，因为投影系数可以直接由内积得到。

Gram-Schmidt 正交化可以把一组线性无关向量转化为一组标准正交向量。它的核心思想是逐步减去已经构造出的正交方向上的投影，只保留新的独立方向。

向量 b 到子空间 S 的正交投影 p 是 S 中距离 b 最近的向量。残差 r = b - p 与子空间 S 中的每个向量都正交。这个“残差正交”条件是最小二乘法的几何基础。

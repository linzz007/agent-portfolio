# 线性代数课程讲义：线性映射、核与像

线性映射 T: V -> W 保持加法和数乘，即 T(u + v) = T(u) + T(v)，并且 T(cv) = cT(v)。在有限维空间中，给定基以后，每个线性映射都可以表示成一个矩阵。

线性映射的核 kernel 是所有被映射到零向量的输入集合，记作 Ker(T) = {v | T(v) = 0}。核描述了映射丢失的信息。核只包含零向量时，线性映射是单射 injective。

线性映射的像 image 是所有可能输出的集合，记作 Im(T) = {T(v) | v 属于 V}。像空间描述了映射能够覆盖的输出范围。如果像空间等于整个目标空间 W，那么线性映射是满射 surjective。

秩-零化度定理说明，对于有限维线性映射 T: V -> W，有 dim(V) = rank(T) + nullity(T)。其中 rank(T) 是像空间维数，nullity(T) 是核空间维数。

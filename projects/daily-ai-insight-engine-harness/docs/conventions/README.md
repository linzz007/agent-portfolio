# 编码规范总览

本目录包含本项目的全部编码规范，AI 编程助手在修改代码时必须遵守。
规范分为以下类别：

| 规范 | 文件 | 说明 |
|------|------|------|
| 命名规范 | naming.md | 文件、类、函数、变量的命名规则 |
| 错误处理 | error-handling.md | 异常处理、日志记录、降级策略 |
| 测试规范 | testing.md | 测试编写、覆盖率、CI 要求 |
| 日志规范 | logging.md | 结构化日志、warning/error 记录 |

## 通用原则

1. **确定性优先**：能确定性地完成的逻辑不调用 LLM
2. **可审计**：每个 stage 的输出都必须落盘，事后可追溯
3. **渐进降级**：LLM 不可用时系统必须仍能运行（fallback）
4. **合同驱动**：跨 stage 数据通过 FIELD_SPEC 合同约束，下游按合同消费
5. **单文件≤300行**：超过需要拆分
6. **单函数≤50行**：保持函数职责单一
